# Nishant Gautam — Personal Portfolio

A modern and responsive personal portfolio website built to showcase my
skills, certifications, learning journey, and professional profile as a
B.Tech Computer Science (Artificial Intelligence) student.

---

## About the Project

This is my personal portfolio website, developed from scratch using
HTML, CSS, and JavaScript.

The main purpose of this project is to create a professional online
presence while applying and improving my frontend development skills.

The website focuses on a clean, modern, dark-themed interface with
smooth scrolling, interactive navigation, animations, and responsive
design.

---

## Features

- Modern dark-themed UI
- Responsive website layout
- Fixed navigation bar
- Smooth scrolling navigation
- Active navigation section highlighting
- Scroll-based reveal animations
- Hero section with profile image
- About Me section
- Skills and technologies section
- Projects section
- Learning journey section
- Certifications section
- Currently Learning section
- Contact section
- Resume access
- GitHub and LinkedIn links
- Certificate document links
